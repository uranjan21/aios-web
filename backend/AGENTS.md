## Read before writing backend code

`backend/CLAUDE.md` is the source of truth for this folder: FastAPI/SQLModel
conventions, the multi-tenancy contract, migration chains, and the backend
gotchas. Do not restate its rules elsewhere — extend it.

## Hard rules (the ones most often broken)

- **Multi-tenant isolation is not optional.** Every user-data table carries
  `user_id UUID FK → users.id`, and every query filters by `current_user.id`
  (or `household_id`). New user-data endpoints need a matching case in
  `tests/test_isolation.py`.
- **SQLModel tables must import `Field` from `sqlmodel`** — pydantic's `Field`
  silently drops `primary_key`.
- **Declare literal routes before `/{id}` param routes**, or the literal is
  swallowed.
- **Async all the way**: DB, HTTP and file I/O.
- **Review every autogenerated migration.** Autogenerate tries to DROP the
  `captures` table because its model isn't imported in `alembic/env.py`. Strip
  unrelated drops before `upgrade head`.
- **Docker has no `--reload`**: after any Python edit run
  `docker compose restart backend` — and `docker compose up -d backend` instead
  if `.env` changed, because `restart` does not re-read `env_file`.
- **Never commit secrets or Utsav's personal data.** A seed-script leak happened
  once; check `seed_dummy_data.py` diffs before committing.

## Tests

`uv run pytest tests/ -q` from `backend/`. `test_auth` and `test_api_mappings`
are host-only, not part of the Docker suite. `test_api_mappings.py` reads the
frontend source under `frontend/` — keep that path in sync if the layout moves.
