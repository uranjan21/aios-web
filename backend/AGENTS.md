# AGENTS.md — backend

The repo-wide agreement is in the root `AGENTS.md`. `backend/CLAUDE.md` is the
source of truth for this folder's conventions. This file is only the short list
of rules that get broken most often.

- **Every query filters on `current_user.id`.** No exceptions. Cross-tenant
  access returns 404.
- **Import `Field` from `sqlmodel`, not pydantic.** Pydantic's silently drops
  `primary_key`, and the table is created without one.
- **Declare literal routes before `/{id}` routes**, or `/accounts/summary` is
  parsed as an account id.
- **Async all the way** — database, HTTP and file I/O. A synchronous call in a
  request handler blocks the whole event loop.
- **Read every autogenerated migration before applying it.** Autogenerate
  proposes dropping tables whose models it cannot see.
- **Never resolve a network resource at import time.** A module-level call that
  reaches the network turns a cold cache into a crash on boot. See
  `app/core/tokens.py`.

## Tests

```bash
cd backend && uv run pytest        # 362 tests
```

`tests/test_api_mappings.py` reads the frontend source under `frontend/` and
checks that every frontend call site has a matching backend route with matching
parameters. If you move the frontend, update its paths.
