Comprehensive design guide for web and mobile applications. Contains 67 styles, 96 color palettes, 57 font pairings, 99 UX guidelines, and 25 chart types across 13 technology stacks. Searchable database with priority-based recommendations.

## Common Rules for Professional UI

### Icons & Visual Elements

- **No emoji icons**: Use SVG icons (Heroicons, Lucide, Simple Icons) instead of emojis like 🎨 🚀 ⚙️.
- **Consistent icon sizing**: Use consistent icon sizes (e.g. 14px or 16px).
- **Cursor pointer**: Add cursor pointer or make sure interactive elements have proper cursor settings.
- **Layout & Spacing**: Keep headers structured and consistent. Follow the specified card layout conventions.
